# Security Policy

P.A.W. is early-stage software. Do not use it to run untrusted agents against sensitive systems.

Report suspected vulnerabilities privately through GitHub security reporting when available. Do not open public issues with exploit details or secrets.

Never submit API tokens, private keys, personal data or unredacted logs in issues or pull requests. Security priorities include least privilege, approval for destructive actions, secret storage outside source control, isolation, resource/network limits, audit trails and explicit recovery semantics.
