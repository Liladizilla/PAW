# P.A.W. Requirements

Commercial standalone Personal Agent Workspace for Linux, Windows and macOS. Local-first, useful offline, optional encrypted sync and bring-your-own model endpoints.

## Agents and tools
Coding, research, automation, testing/debugging and user-created agents. Tools include shell, code editor/files, Git/GitHub, browser automation, HTTP APIs, scheduled tasks and local models. Hierarchical teams, configurable autonomy, scoped memory and live inspection/pause/redirect/intervention.

## 3D workspace
Immersive spatial world, infinite canvas with semantic zones, free orbit/pan/zoom/focus/reset, solid modular machine nodes, mixed industrial materials, dark graphite with vivid accents, physical branching tubes, force/collision simulation, adaptive dense workspace, hover preview and pinned inspector. Mouse/keyboard/shortcuts, node dragging, port connections, multi-select, context menus, teams, undo/redo, accessibility and comfort settings. Adaptive quality and high-quality mode.

## Architecture
Electron, Babylon.js, dedicated distributed runtime, hybrid typed graph and bounded goal-driven execution, event-driven durable history, SQLite plus filesystem and optional vector storage, provider adapters, SDK and permissioned plugins/MCP.

## Execution and recovery
Typed graph rules, bounded autonomy, mixed concurrency, policy-based failure handling, graceful cancellation and force-stop. Manual crash recovery, event history and replay, persistent pending approvals, workspace-centric data hierarchy, scoped memory, trusted core plus plugins, full first-release ambition delivered in milestones.

## Security
Per-agent permissions, human approval for destructive actions, credential vault, isolated execution, resource/time limits, network controls, audit logs, rollback support and filesystem restrictions.

## Constraints
Modest hardware, useful offline, cross-platform, automated tests, benchmarks and real-machine verification. Public repository.
