# Engineering Roadmap

## M1 — Buildable foundation
Stable desktop scaffold, typed contracts, security boundaries, CI, renderer/engine benchmark and architecture decisions.

## M2 — Real local execution
Runtime service, graph executor, bounded planner, scheduler, model adapters, first tools and policy enforcement.

## M3 — Persistence and recovery
SQLite schema, durable event stream, memory scopes, approvals, audit history, checkpoints, manual recovery and safe replay.

## M4 — Spatial workspace
Real runtime visualization, physical nodes, branching tubes, camera and manipulation, selection, inspector, semantic zones, undo/redo and adaptive physics.

## M5 — Security and distributed extensions
Credential vault, isolation, resource/network controls, SDK/MCP, authenticated remote workers and optional encrypted sync.

## M6 — Release hardening
Accessibility, adaptive graphics, installers, upgrades, recovery tests, CI artifacts, performance budgets and Linux/Windows/macOS verification.

Every milestone requires automated tests and documented verification. Preview data must remain clearly labeled until connected to a real runtime.
